3 METHOD
We address the problem ofsustained harness optimizationunder non-stationary task streams. Un-
like prior work that treats memory as a static archive or a raw-text log, we propose aMeta-Memory
framework that maintains a dynamic, editable set of causal rules. We formulate the complete op-
timization cycle as a state-space model and introduce theoretical innovations in credit assignment,
dynamic confidence calibration, and concept-drift resilience.

3.3 CONTEXT-AWAREATOMICEDITOPERATIONS
To enable precise and traceable memory updates, we define an extended edit space of five context-
aware atomic operations that directly address the needs of lifelong adaptation. When a rule fails on
new data, we may narrow its scope rather than discard it entirely; when a rule is too broad, we split
it into specialized subrules for different regimes; and when multiple high-confidence rules become
redundant, we merge them to keep the memory compact. We denote this operation set as
O={ADD,DELETE,REFINE,SPLIT,MERGE}.(9)
Given the reflection setR t from the judge, the executor translates each reflectionρ∈R t into one of
these operations: ADDinserts a new rule when the judge identifies an uncovered pattern; DELETE
removes a consistently failing rule; REFINEnarrows a rule’s applicability when it underperforms on
a specific subset; SPLITdecomposes a broad rule into specialized subrules; and MERGEconsolidates
redundant high-confidence rules.
Each edit is treated as an independent patch, carrying its own influence score and targeting a spe-
cific rule. When multiple harness components change in a single round, patches are never merged;
instead, each is separately logged with its own status, pass/fail results, and rollback capability. This
patch-wise design ensures that every update remains attributable, directly addressing the credit at-

4 EXPERIMENT
Our experimental investigation centers on four key research questions: Q1: Can Meta-Memory sus-
tain or enhance the long-term average performance of the harness under sequential task distribution
shifts, where the original Meta-Harness tends to degrade due to forgetting? Q2: Does patch-level
credit assignment enable more precise identification of effective edits, thereby reducing wasteful
search steps and accelerating optimization? Q3: Does the dual-memory architecture (stable vs.
volatile) effectively isolate harmful noise, improve the quality of the final rule set, and yield in-
terpretable rules? Q4: Do these improvements transfer consistently across a broad range of task
domains, including classification, reasoning, and interactive agentic environments, without overfit-
ting to any single benchmark?
